Experiment 10 curated files package

Includes the cleaned notebook with outputs, final report in PDF and DOCX, four-figure ZIP, and nine CSV result files.

The LFW embeddings dataset (lfw_vit_embeddings.csv) is not included because it was not available among the uploaded files when this package was assembled. Keep your local copy with this archive if you need to rerun the notebook.

Notebooks for Experiments 04–09 and alternate exploratory notebook versions are not included. Review the report before publication: these results use synthetic shifts and repeated samples from the same underlying pools, so they do not establish real-world chronological drift performance.
