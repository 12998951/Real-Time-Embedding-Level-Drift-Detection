# Experiment 20

## Title
Paired Identity-Level Evaluation of Within-Identity Embedding Drift Detection Under Multiple Controlled Biometric Acquisition Changes.

## Overview
This experiment investigates reference-relative face embedding displacement across illumination geometry conditions using the Cropped Extended Yale B dataset.

## Research Artifacts
- Experimental notebook
- Integrated research manuscript
- Frozen dataset package
- Supporting audit and provenance records
- Four research figures

## Dataset
The frozen dataset package and its checksum manifest are maintained separately from this repository because of the dataset archive size.

## Research Status
The experiment's administrative closure and manuscript audit records are included in the supporting documentation. The manuscript audit contains a structural check requiring review; it should not be interpreted as a fully passed audit.

## Limitations
- The acquisition conditions are not controlled transformations.
- The dataset archive has not been authenticated against the official UCSD checksum.
- Exact model-weight checksum preservation is incomplete.
- The evaluation does not establish real-world recognition accuracy or deployment readiness.
