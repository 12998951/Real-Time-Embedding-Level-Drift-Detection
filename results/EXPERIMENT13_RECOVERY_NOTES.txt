6. PROVENANCE LIMITATIONS
-------------------------
The original TFDS filesystem enumeration order was not independently
verified against the original execution environment.

The regenerated dataset ordering was reconstructed using the
available TFDS path-making logic and checked for identity alignment.

However, this does not establish that every dataset index maps
to exactly the same original image as in the original execution.

Consequently:
- These files must be described as regenerated artifacts.
- They must not be described as exact original-file recoveries.
- Byte-for-byte equivalence with the original outputs is not established.
- Exact row-by-row equivalence with the original dataset ordering
  is not established.

The SHA-256 checksums in the recovery manifest identify the
regenerated files created in this recovery run. They do not prove
equivalence to missing original files.
