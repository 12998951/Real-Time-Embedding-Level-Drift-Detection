### Exact normalization formula

The package implements:

    (np.float32(image) - 127.5) / 127.5

This maps the original 0-255 pixel intensity range to approximately
-1 to +1.

### Verified embedding pipeline

1. Each input image is resized to 160 x 160 using cv2.resize().
2. Fixed image standardization is applied.
3. The normalized image batch is converted to float32.
4. The batch is passed to the FaceNet model using model.predict().
5. The model returns 512-dimensional embeddings.

### Face detection and alignment scope

The experiment uses FaceNet.embeddings(), not FaceNet.extract().
The extract() method invokes the package's face extraction pathway,
but that pathway is not used by this experiment's embedding call.
Therefore, MTCNN face detection and cropping are not part of the
verified embedding-generation pathway.
